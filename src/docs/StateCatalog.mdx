# State Catalog

Este catálogo documenta todos os estados possíveis dos componentes do design system, organizados por categoria (Atoms, Molecules, Organisms).

## Atoms

### Button

| Estado     | Descrição           | Como Ativar                | Visual                                     |
| ---------- | ------------------- | -------------------------- | ------------------------------------------ |
| `default`  | Estado padrão       | Estado inicial             | Botão com estilo padrão                    |
| `hover`    | Mouse sobre o botão | Passar mouse sobre o botão | Botão com estilo de hover                  |
| `active`   | Botão pressionado   | Clicar e segurar o botão   | Botão com estilo de active                 |
| `focus`    | Botão com foco      | Tab ou clique              | Botão com outline de foco                  |
| `disabled` | Botão desabilitado  | `disabled={true}`          | Botão com opacidade reduzida, não clicável |
| `loading`  | Botão carregando    | `loading={true}`           | Botão com spinner, desabilitado            |

**Variantes:**

- `primary`: Botão primário (azul)
- `secondary`: Botão secundário (cinza)
- `error`: Botão de erro (vermelho)
- `outline`: Botão com borda
- `ghost`: Botão sem fundo

## Organisms

| Estado      | Descrição        | Como Ativar                 | Visual                              |
| ----------- | ---------------- | --------------------------- | ----------------------------------- |
| `closed`    | Fechado          | Estado inicial              | Command palette oculto              |
| `open`      | Aberto           | `open={true}` ou Cmd/Ctrl+K | Command palette visível com overlay |

**Estados Internos:**

- `searchQuery`: String da busca atual

### Toast

**Variantes:**

- `success`: Toast verde (sucesso)

- `info`: Toast azul (informação)

**Estados de Duração:**

- `auto-dismiss`: Fecha automaticamente após duração
- `persistent`: Permanece até fechar manualmente

## Transições de Estados

### Padrões Comuns

1. **Abrir/Fechar**: `closed` → `animating` → `open` → `animating` → `closed`
2. **Loading**: `idle` → `loading` → `success` ou `error`
3. **Interação**: `default` → `hover` → `active` → `default`
4. **Foco**: `default` → `focus` → `default`

### Exemplos de Transições

#### Button

```
default → hover → active → default
default → focus → default
default → disabled
```

#### Input

```
default → focus → typing → blur → default
default → error → focus → typing → blur → default
```

#### CommandPalette

```
closed → open → searching → selected → action → closed
```

#### Toast

```
entering → visible → (auto-dismiss) → exiting → dismissed
entering → visible → (manual dismiss) → exiting → dismissed
```

#### Stepper

```
pending → active → completed → (next step) active
pending → active → error → (fix) active → completed
```

## Diagramas de Estado

### CommandPalette State Machine

```
[closed] --Cmd+K--> [open]
[open] --Escape--> [closed]
[open] --type--> [searching]
[searching] --ArrowUp/Down--> [selected]
[selected] --Enter--> [action] --> [closed]
[open] --click outside--> [closed]
```

### Toast State Machine

```
[entering] --> [visible]
[visible] --duration--> [exiting]
[visible] --dismiss--> [exiting]
[exiting] --> [dismissed]
```

### Stepper State Machine

```
[pending] --next--> [active]
[active] --validate & next--> [completed]
[active] --validate fail--> [error]
[error] --fix--> [active]
[completed] --back--> [active]
```
