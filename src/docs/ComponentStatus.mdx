# Component Status

The design system ships **62 components** across three layers. Every component is required to include the same file set — `.tsx`, `.test.tsx`, `.stories.tsx`, `index.ts` — per `.claude/rules/components.md`.

## Inventory

| Primitives |    23 |    23 / 23 |          23 / 23 |
| Components |    37 |    37 / 37 |          32 / 37 |
| Layouts    |     2 |      2 / 2 |            0 / 2 |
| **Total**  |    62 |    62 / 62 |          55 / 62 |

## Stability

All 62 shipping components are **Stable**. There are currently no Beta, Experimental, or Deprecated items in the surface. Stability is gated by three checks: the required file set, the ≥80% per-component test coverage threshold (`.claude/rules/testing.md`), and WCAG 2.1 AA conformance for keyboard, ARIA, and focus management.

## Test coverage gaps

Seven components ship without a `.test.tsx` at the component directory:

- **Five composed patterns** — `DashboardLayout`, `DataTablePattern`, `FormWizardPattern`, `LoginBox`, `SearchAndFilterPattern`. These are thin compositions over already-tested primitives and components; the wrapped surface is exercised indirectly.
- **Two layouts** — `Container`, `Stack`. Structural-only, no logic to assert beyond render; tests were not authored at the time the layer was added.

These gaps don't block shipping under the present file-set gate but are visible here so any future test sweep has a starting list.

## Where to look

- `.claude/rules/components.md` — file-set and prop discipline.
- `.claude/rules/testing.md` — coverage threshold and assertion style.
- `.claude/rules/colors.md` — semantic color vocabulary that every component consumes.
