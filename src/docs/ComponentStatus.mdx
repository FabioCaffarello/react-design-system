# Component Status

The design system ships **64 components** across three layers. Every component is required to include the same file set — `.tsx`, `.test.tsx`, `.accessibility.test.tsx`, `.stories.tsx`, `index.ts` — per `.claude/rules/components.md`.

## Stability

All 64 shipping components are **Stable**. There are currently no Beta, Experimental, or Deprecated items in the surface. Stability is gated by three checks: the required file set, the ≥80% per-component test coverage threshold (`.claude/rules/testing.md`), and WCAG 2.1 AA conformance for keyboard, ARIA, and focus management.

## Test coverage gaps

None. Every component directory ships a direct `.test.tsx` and `.accessibility.test.tsx` — enforced by `scripts/validate-file-set.mjs` with zero grandfathered exceptions. A previous version of this page listed seven components without a direct test file (five composed patterns plus the two layouts); that gap was closed by a later test sweep, and any new component cannot land without the full file set.

## Where to look

- `.claude/rules/components.md` — file-set and prop discipline.
- `.claude/rules/testing.md` — coverage threshold and assertion style.
- `.claude/rules/colors.md` — semantic color vocabulary that every component consumes.
