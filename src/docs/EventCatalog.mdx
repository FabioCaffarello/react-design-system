# Event Catalog

Este catálogo documenta todos os eventos emitidos pelos componentes do design system, organizados por categoria (Atoms, Molecules, Organisms).

## Atoms

### Button

| Evento | Descrição | Parâmetros | Quando é Disparado |
|--------|-----------|------------|-------------------|
| `onClick` | Clique no botão | `(event: MouseEvent) => void` | Quando o usuário clica no botão |
| `onMouseEnter` | Mouse entra no botão | `(event: MouseEvent) => void` | Quando o cursor entra na área do botão |
| `onMouseLeave` | Mouse sai do botão | `(event: MouseEvent) => void` | Quando o cursor sai da área do botão |
| `onFocus` | Botão recebe foco | `(event: FocusEvent) => void` | Quando o botão recebe foco (teclado ou mouse) |
| `onBlur` | Botão perde foco | `(event: FocusEvent) => void` | Quando o botão perde foco |

### Input

| Evento | Descrição | Parâmetros | Quando é Disparado |
|--------|-----------|------------|-------------------|
| `onChange` | Valor do input muda | `(event: ChangeEvent<HTMLInputElement>) => void` | Quando o valor do input é alterado |
| `onFocus` | Input recebe foco | `(event: FocusEvent) => void` | Quando o input recebe foco |
| `onBlur` | Input perde foco | `(event: FocusEvent) => void` | Quando o input perde foco |
| `onKeyDown` | Tecla pressionada | `(event: KeyboardEvent) => void` | Quando uma tecla é pressionada no input |
| `onKeyUp` | Tecla liberada | `(event: KeyboardEvent) => void` | Quando uma tecla é liberada no input |

## Organisms

### CommandPalette

| Evento | Descrição | Parâmetros | Quando é Disparado |
|--------|-----------|------------|-------------------|
| `onOpenChange` | Estado de abertura muda | `(open: boolean) => void` | Quando o command palette abre/fecha |
| `onSearch` | Busca realizada | `(query: string) => void` | Quando o usuário digita na busca (implícito via onChange do input) |
| `onCommandSelect` | Comando selecionado | `(command: CommandItem) => void` | Quando um comando é selecionado (via action do item) |

**Eventos de Teclado:**
- `Cmd/Ctrl + K`: Abre o command palette
- `Escape`: Fecha o command palette
- `Arrow Up/Down`: Navega entre comandos
- `Enter`: Seleciona o comando atual

### Toast

| Evento | Descrição | Parâmetros | Quando é Disparado |
|--------|-----------|------------|-------------------|
| `onDismiss` | Toast fechado | `(id: string) => void` | Quando um toast é fechado (auto-dismiss ou manual) |
| `onActionClick` | Ação do toast clicada | `(action: ToastAction) => void` | Quando o botão de ação do toast é clicado |

**Eventos do Hook `useToast`:**
- `toast.success()`: Cria um toast de sucesso
- `toast.error()`: Cria um toast de erro
- `toast.warning()`: Cria um toast de aviso
- `toast.info()`: Cria um toast informativo
- `toast.clearAll()`: Remove todos os toasts

## Padrões de Eventos

### Convenções de Nomenclatura

- **onChange**: Usado para mudanças de valor/estado
- **onOpenChange**: Usado para componentes que abrem/fecham (modais, dropdowns, etc.)
- **onClick**: Usado para cliques diretos
- **onSelect**: Usado para seleção de itens de lista
- **onFocus/onBlur**: Usado para eventos de foco

### Tipos de Eventos

1. **Eventos de Interação**: `onClick`, `onChange`, `onSelect`
2. **Eventos de Estado**: `onOpenChange`, `onValueChange`
3. **Eventos de Teclado**: `onKeyDown`, `onKeyUp`
4. **Eventos de Foco**: `onFocus`, `onBlur`
5. **Eventos de Mouse**: `onMouseEnter`, `onMouseLeave`

## Exemplos de Uso

### Exemplo: CommandPalette

```tsx
<CommandPalette
  items={commands}
  open={isOpen}
  onOpenChange={(open) => {
    console.log('Command palette', open ? 'opened' : 'closed');
    setIsOpen(open);
  }}
/>
```

### Exemplo: Toast

```tsx
const toast = useToast();

toast.success('Success!', 'Operation completed', {
  onDismiss: (id) => {
    console.log('Toast dismissed:', id);
  },
  action: {
    label: 'View',
    onClick: () => {
      console.log('Action clicked');
    },
  },
});
```

### Exemplo: Stepper

```tsx
<Stepper
  steps={steps}
  currentStep={currentStep}
  onStepChange={(stepIndex) => {
    console.log('Step changed to:', stepIndex);
    setCurrentStep(stepIndex);
  }}
  onComplete={() => {
    console.log('Stepper completed!');
  }}
/>
```
