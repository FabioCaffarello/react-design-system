## State Management

The TableProvider manages multiple state domains:

1. **Pagination State**: Current page, page size, total pages
2. **Sorting State**: Sort column and direction
3. **Filter State**: Active filters and their values
4. **Selection State**: Selected row IDs

## Modes

### Client-side Mode

- All data processing happens in the provider
- Filtering, sorting, and pagination are applied to the data array
- No external callbacks required

### Server-side Mode

- Data processing happens on the server
- Provider only manages UI state
- Requires `onPageChange`, `onSort`, `onFilter` callbacks
- External `total` prop required

## Controlled vs Uncontrolled

The provider supports both controlled and uncontrolled modes for all state domains:

- **Controlled**: Parent component manages state via props
- **Uncontrolled**: Provider manages internal state
